# ILang – hlavní rozcestník výukových aplikací

Tento balíček obsahuje hlavní stránku webu ILang:

- `index.html`
- `assets/logo-ilang.png`

Tato verze je určena pro situaci, kdy má každá aplikace vlastní GitHub repozitář a vlastní GitHub Pages adresu.

## Jak přidat další aplikaci

1. Vytvoř novou aplikaci v samostatném repozitáři.
2. Zapni pro ni GitHub Pages.
3. Zkopíruj její adresu.
4. V hlavním `index.html` přidej další kartičku s odkazem na novou adresu.

## Důležité

Do repozitáře hlavního rozcestníku nahraj přímo:

- `index.html`
- složku `assets`

Nahrávej obsah složky, ne samotný ZIP.
